# 3.1.0-beta.2

- **Listas na página de um item** (ex.: "outros imóveis"): os cartões mostravam o item da página em vez de cada item da lista. As tags com "item atual" passam a usar o item do cartão quando ele é outro item da mesma coleção.
- **ID de consulta `flashsite_outros`:** numa lista do Elementor (Loop/Collection) com este ID, o item da página fica de fora da lista.
