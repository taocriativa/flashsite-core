# 3.1.0-beta.3

- **Tipos de imóvel ampliados:**
  - Brasil: Studio / kitnet, Flat, Sítio / chácara, Fazenda, Terreno em condomínio, Prédio.
  - Portugal: Vivenda, Quinta / herdade, Armazém, Prédio.
- **Tipo de imóvel aceita tipos novos na ficha** (como a localização): quem cadastra pode criar um tipo que não esteja na lista.
- **Termos novos chegam com a atualização:** os termos de base das coleções passam a ser criados também quando a versão do Core muda (antes, só quando o conjunto de coleções ativas mudava).
