# 3.1.0-beta.16

- **Contador (`fs-contador`):** classe global para números que contam de 0 até o valor quando aparecem na tela ("+500.000", "100 mil+", "98%"). Mantém prefixo e sufixo, respeita o separador de milhar e "reduzir movimento". Duração por `--fs-contador-duracao` (ms). Recurso comum a qualquer site.
