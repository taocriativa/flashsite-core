# FlashSite Core 2.6.0-beta.14 · Preset Menu (pratos)

- Novo preset `prato` (/menu/): categoria (Entradas, Pratos, Sobremesas, Bebidas, editável), preço ou sob consulta,
  descrição curta, porção, destaque, etiqueta, "Esgotado hoje", 14 alergénios da UE, vegetariano/vegano/sem glúten.
- `settings.hide_field`: campo bool que esconde o item do site sem o apagar (listagem, tags de lista, Loop Grid).
- `settings.archive_group_by`: listagem agrupada por taxonomia (uma secção por categoria, pela ordem do preset).
- Demo Kit: presets sem galeria recebem a primeira imagem como foto do item. Demo Kit 1.2.0 com 9 pratos.
- Teste PratoPresetTest.
