# FlashSite Core 1.6.0 — Elementor Integration

## Entregas
- formalização da integração nativa com Elementor via Dynamic Tags
- grupo de tags `FlashSite Core` no selector do Elementor
- expansão do catálogo de tags com:
  - WhatsApp Link
  - Admin Email
  - City / Region
- manifesto central de classes de tags para manutenção e testes

## Tags disponíveis
- Business Name
- Phone
- WhatsApp
- WhatsApp Link
- Email
- Admin Email
- Address
- City / Region
- Website
- Tagline
- Logo Light
- Logo Dark
- Primary Color
- Secondary Color
- Accent Color

## Notas
- a integração permanece opcional e só actua quando o Elementor estiver carregado
- o plugin continua funcional sem Elementor
