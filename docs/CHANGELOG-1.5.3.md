# FlashSite Core 1.5.4 — UI refinement integration

## Added
- Integrated refined admin visual layer directly into the plugin.
- Improved visual hierarchy for headers, cards, metrics, summary tables and wizard steps.

## Changed
- Reduced excessive orange outlines and reserved primary color for actions and active states.
- Standardized button hierarchy between primary and secondary actions.
- Improved data readability in business summary and safety screens.

## Safety
- No lifecycle or storage contract changes.
- This release focuses on admin UX polish while preserving the validated 1.5.x data-safety behavior.
