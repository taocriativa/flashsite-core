# FlashSite Core 1.5.2 — Changelog

## Foco da versão
Consolidação operacional e refinamento visual pragmático do painel administrativo.

## Entradas principais
- bump de versão para 1.5.2
- refinamento visual do admin header, cards, ações e estados
- reforço da comunicação de modo de proteção em coexistência legada
- melhoria da leitura operacional em Dashboard e Segurança de Dados

## Observações
Esta versão mantém a linha de hardening da 1.5.1 e melhora a consistência visual sem introduzir redesign estrutural completo.
