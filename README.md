# FlashSite Core — 1.3.0

Versão 1.3.0 de consolidação técnica do núcleo operacional da FlashSite para WordPress.

Inclui:
- BusinessProfile estruturado por blocos
- Setup Wizard administrativo
- branding com logos e cores
- shortcodes de output
- Dynamic Tags iniciais para Elementor
- uninstall conservador por padrão

## Notas da 1.3.0

Esta release endurece a base 1.0.0 com infraestrutura de testes, documentação operacional e preparação segura para a próxima fase do produto.
A base do domínio permanece no FlashSite Core, enquanto Elementor atua apenas como camada de consumo.

## Política de dados

O plugin passa a manter também `flashsite_data_version`, preparando o caminho para migrações futuras de schema sem quebrar instalações já existentes.
